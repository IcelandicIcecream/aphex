MCP guides, like skills: `mcp.guides` lists markdown guides (a homepage, a kind of business, SEO) that a connected agent reads with the new `get_guide` tool when it's on that job. The instructions sent on connecting list them a line each, so the depth costs nothing until it's needed. A guide's content may be a function of the site and caller, and returning null leaves it out.
