Organization lists can link to each organization's public site. Opt-in: set `organizationSiteUrl` in the config and every row (your organizations, and God Mode's) gets a "View site" link that opens in a new tab, so a super admin can look at a site without being a member. In God Mode the switch button now only shows for organizations you belong to, uses an arrow rather than an external-link icon, and a failed switch shows an error instead of failing silently.
